# @bonjoski Default Community & Security Files

This repository provides account-wide default health, community, and security configuration for [@bonjoski](https://github.com/bonjoski) repositories.

---

## ⚖️ Safe Harbor & Developer Tooling Scope

All repositories under `@bonjoski` operate strictly within personal, single-developer workstation Developer Experience (DevEx) boundaries:

- **100% Local Workstation Execution:** All tools and runtimes execute exclusively on the local machine (`localhost`), with zero multi-tenant cloud control planes, zero centralized fleet telemetry, and zero enterprise SaaS subscriptions.
- **Public OS Primitives:** Execution confinement and secrets management utilize standard, public operating system primitives (Apple Seatbelt, Linux Landlock LSM, macOS Hypervisor, local Touch ID / TPM2).
- **Personal Developer Productivity:** Built for individual software engineering and agentic workflows (Antigravity, Cursor, Claude Code) without commercial competition against enterprise security offerings.
- **Permissive Open Source:** Distributed under permissive open-source licenses (MIT / Apache-2.0).
